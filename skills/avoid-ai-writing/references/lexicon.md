# 词表（lexicon）

本文件同时是 `scripts/scan.js` 的词表数据源：改表格就是改扫描行为，改完跑一遍 `npm test`。

## 格式约束

脚本按下面的约定解析，改动前先读：

- 每个分区是一个二级标题，标题以“第一档”“第二档”“第三档”“营销腔”“公文腔”开头
- 每个分区一张三列表格：原词、改为、放行语境
- 原词里用 `／` 分隔同义变体；`……` 表示中间可以夹 0 到 12 个字（不跨标点）
- 放行语境里用反引号包住的搭配是精确放行：命中词落在这些搭配里时不报；其余文字是给人看的语境说明
- 两个词重叠时（“颠覆性”和“颠覆”），只报较长的那个

| 分区 | 规则 id | 级别 | 成簇基准 |
|---|---|---|---|
| 第一档 | `lexicon-tier1` | 二级 | 见一个报一个 |
| 第二档 | `lexicon-tier2` | 三级 | 同一段两个以上才报 |
| 第三档 | `lexicon-tier3` | 三级 | 按密度报：每百字超过 2 次 |
| 营销腔 | `lexicon-marketing` | 二级 | 见一个报一个 |
| 公文腔 | `lexicon-officialese` | 三级 | 见一个报一个，受场景宽严控制 |

场景宽严会在成簇基准上加码，见 [scenes-and-voice.md](scenes-and-voice.md)。

| 顶层设计 | 整体规划 | 引用政策文件原文时 |

## 第三档：高密度才标记

正常词汇，全文密密麻麻才是 AI 味。换成具体内容：数字、对比、实例；换不动就删。

| 原词 | 改为 | 放行语境 |
|---|---|---|
| 重要／重大／关键／核心 | 换成具体内容 | |
| 创新／颠覆／变革 | 换成具体内容 | |
| 高效／优质／卓越／领先 | 换成具体内容 | |
| 完善／健全／优化 | 换成具体内容 | |
| 推动／促进／加强／提升 | 换成具体内容 | |
| 广泛／深入／全面 | 换成具体内容 | |
| 日益／愈发／不断 | 越来越，或给出变化幅度 | |

## 营销腔：见即替换

说清到底好在哪，说不出就删。

| 原词 | 改为 | 放行语境 |
|---|---|---|
| 匠心打造／匠心之作 | 说清工艺或用料 | |
| 极致体验／极致性能／极致享受 | 说清快在哪、好在哪 | |
| 尊享／臻选／甄选 | 删 | |
| 殿堂级／史诗级 | 说清比同类好在哪 | |
| 天花板 | 说清比同类好在哪 | 建筑语境：`天花板高度`、`天花板吊顶` |
| 颠覆想象／重新定义 | 说清变了什么 | |
| 超乎想象／前所未有 | 说清和之前比差在哪 | |
| 引领潮流／引领未来 | 删 | |

## 公文腔：按场景处理

公文里是惯例，公文·通知场景默认放过；用户要求“去机关腔”时加 `--officialese`，所有场景按严处理。

| 原词 | 改为 | 放行语境 |
|---|---|---|
| 高度重视 | 说明做了什么 | |
| 密切关注 | 说明具体在关注什么 | |
| 稳步推进／扎实推进 | 说明推进到哪了 | |
| 有序开展／扎实做好 | 说明开展了什么 | |
| 进一步 | 删，或说清比之前多做了什么 | |
| 切实／着力 | 删 | |
| 认真贯彻／全面落实 | 说明落实了哪条、怎么落实 | |
| 持续发力／全力以赴 | 说明投入了什么 | |
| 取得……成效／取得……进展 | 说明成效是什么 | |
| 高质量发展 | 说清哪项指标变好 | |
