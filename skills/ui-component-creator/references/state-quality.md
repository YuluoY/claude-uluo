# 完整状态与质量保障

组件创建 Phase 4 的方法论。定义四态矩阵和质量检查标准。

---

## 四态矩阵

每个组件必须考虑四种状态——**缺一不可**。只写 success 状态的组件是半成品。

### 状态定义

| 状态 | 触发条件 | 设计目标 |
|------|---------|---------|
| **Loading** | 异步数据加载中 | 让用户知道在等待，保持布局稳定 |
| **Error** | 加载失败 / 运行出错 | 明确告知出错，提供恢复操作 |
| **Empty** | 数据为空 | 引导用户行动，不显示空白 |
| **Success** | 数据正常加载 | 完整功能 + 边界情况处理 |

### 状态矩阵模板

```markdown
| 状态 | 触发条件 | UI 表现 | 交互 |
|------|---------|---------|------|
| Loading | isLoading=true | 骨架屏（保持布局） | 禁用操作 |
| Error | error != null | 错误信息 + 重试按钮 | 可点击重试 |
| Empty | data.length === 0 | 空状态插图 + 引导文案 | 引导操作 |
| Success | data.length > 0 | 正常渲染 | 全部交互可用 |
```

### Loading 状态

- **骨架屏 > spinner**：骨架屏保持布局稳定，减少 CLS（Cumulative Layout Shift）
- **延迟显示**：加载 < 200ms 不显示 loading（避免闪烁）
- **超时处理**：加载 > 10s 显示超时提示

### Error 状态

- **明确错误类型**：网络错误 / 权限错误 / 数据错误，分别处理
- **不暴露技术细节**：用户看到"网络连接失败"，不是"TypeError: Cannot read property 'map' of undefined"
- **提供恢复操作**：重试 / 返回 / 联系支持

### Empty 状态

- **区分原因**：未搜索到结果 / 无权限 / 未初始化
- **引导行动**：告诉用户下一步做什么（创建数据 / 调整筛选 / 联系管理员）
- **不显示空白**：空白让用户以为出错了

### Success 边界情况

- 极长文本：截断 + tooltip / 换行
- 极多数据：虚拟滚动 / 分页
- 极宽极窄：响应式布局验证
- 特殊字符：HTML 转义 / emoji 渲染

## 质量检查清单

### 无障碍（a11y）

- [ ] **语义化 HTML**：用 `<button>` 不用 `<div @click>`，用 `<nav>` 不用 `<div class="nav">`
- [ ] **ARIA 属性**：动态内容有 `aria-live`，图标按钮有 `aria-label`
- [ ] **键盘可达**：所有交互元素 Tab 可达，Enter/Space 可触发
- [ ] **焦点管理**：弹窗打开聚焦内部，关闭归还焦点
- [ ] **颜色对比度**：文字与背景对比度 ≥ 4.5:1（WCAG AA）
- [ ] **不依赖颜色**：错误状态不仅变红，还要有图标/文字

### 国际化（i18n）

- [ ] **所有用户可见文本走 i18n**：不硬编码中文/英文
- [ ] **日期/数字本地化**：用 Intl API，不手动拼接
- [ ] **复数处理**：用 ICU MessageFormat，不写 `if (count === 1)`
- [ ] **文本长度弹性**：德语比英语长 30%，布局要适应
- [ ] **RTL 支持**：如需支持阿拉伯语，布局逻辑用 `start/end` 不用 `left/right`

### 样式分离验证（Style Separation）

**三层分离检查**：

- [ ] **结构层样式独立**：布局/尺寸/定位样式与风格无关，用固定值或独立 token（不引用语义 token）
  - 判定标准：结构层样式在切换风格预设时不需要改动
- [ ] **语义层 token 完整**：颜色/间距/字号/圆角/阴影全部走语义 token（如 `var(--color-primary)`），不硬编码具体值
  - 判定标准：搜索组件源码无 `#[0-9a-fA-F]{3,8}` 字面量、无 `Npx` 间距/字号字面量（结构层除外）
- [ ] **风格层由预设提供**：组件代码不实现风格层 token 值，由 `references/style-presets/` 预设文件提供
  - 判定标准：组件内无 `--color-primary: #XXX` 的赋值，只有 `var(--color-primary)` 的引用

**风格切换测试**：

- [ ] **至少切换 2 种风格预设**：从 apple/vercel/github/material 中选择至少 2 种切换验证 UI 正确
  - 判定标准：切换预设后组件渲染正确，无样式破损
- [ ] **切换风格时组件代码零改动**：仅切换预设文件，组件源码无任何修改
  - 判定标准：git diff 显示组件源码无变更，仅预设引用变更

**业务层继承检查**（如适用）：

- [ ] **业务层组件继承原子层语义 token**：业务层不引入新硬编码，可定义业务语义 token 但值仍引用语义层
  - 判定标准：业务层组件可定义 `--color-user-avatar-border: var(--color-border)`，但不直接写 `--color-user-avatar-border: #ddd`

**暗色模式**（风格层的一部分）：

- [ ] **暗色模式自动适配**：所有颜色走 token，暗色模式由风格层预设提供，组件代码无需感知
  - 判定标准：切换暗色预设后无硬编码颜色残留

### 响应式

- [ ] **移动端**（< 768px）：布局是否合理？触摸目标 ≥ 44px？
- [ ] **平板**（768-1024px）：布局是否合理？
- [ ] **桌面**（> 1024px）：布局是否合理？
- [ ] **超宽屏**（> 1920px）：内容是否撑满或合理限制最大宽度？

### 性能

- [ ] **避免不必要 re-render**：React 用 memo/useMemo/useCallback，Vue 用 computed/shallowRef
- [ ] **大列表虚拟化**：> 100 条数据用虚拟滚动
- [ ] **图片懒加载**：`loading="lazy"` 或 IntersectionObserver
- [ ] **防抖节流**：搜索输入、resize 监听、scroll 监听
- [ ] **代码分割**：重组件动态导入

### 安全

- [ ] **用户输入转义**：不直接 `v-html` / `dangerouslySetInnerHTML`
- [ ] **不信任外部数据**：校验 API 返回的数据结构
- [ ] **XSS 防护**：URL 参数校验，不直接拼接到 href/src
