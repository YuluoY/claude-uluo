## 4. API 契约

### 4.1 输入（Props / Attributes）

| 名称 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| items | `Item[]` | 是 | — | 数据列表 |
| pageSize | `number` | 否 | `10` | 每页条数 |
| loading | `boolean` | 否 | `false` | 加载状态 |

### 4.2 输出（Emits / Events / Callbacks）

| 名称 | 参数 | 触发时机 |
|------|------|---------|
| select | `(item: Item)` | 用户点击项目时 |
| change | `(value: string, oldValue: string)` | 选中项变化时 |

### 4.3 插槽（Slots / Children）

| 名称 | 作用域参数 | 默认内容 | 说明 |
|------|----------|---------|------|
| default | `{ item, index }` | `item.name` | 自定义项目渲染 |
| header | — | — | 列表头部内容 |
| footer | `{ total }` | — | 列表底部内容 |

### 4.4 双向绑定

| 名称 | 类型 | 说明 |
|------|------|------|
| v-model / value | `string` | 选中项 ID |

### 4.5 状态管理

| 状态 | 模式 | 说明 |
|------|------|------|
| selectedId | 非受控（默认）+ 受控（可选） | 内部管理，可通过 v-model 受控 |
| page | 内部状态 | 分页内部管理，不暴露 |

## 5. 四态矩阵

| 状态 | 触发条件 | UI 表现 | 交互 |
|------|---------|---------|------|
| Loading | `loading=true` | 骨架屏 | 禁用点击 |
| Error | [错误条件] | 错误信息 + 重试 | 可点击重试 |
| Empty | `items.length === 0` | 空状态插图 + 引导 | 引导创建数据 |
| Success | `items.length > 0` | 正常列表 | 全部交互可用 |
