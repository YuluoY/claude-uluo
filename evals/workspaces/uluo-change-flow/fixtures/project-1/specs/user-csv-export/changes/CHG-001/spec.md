# 支持 Excel 导出 变更 Spec

> 日期: 2026-06-25 | 作者: huyongle | 变更编号: CHG-001 | 关联特性: specs/user-csv-export/

## 变更背景

### 变更触发原因

运营团队反馈 CSV 文件在 Excel 中打开时存在中文乱码、长数字被科学计数法显示、日期格式错乱等问题，影响报表制作效率。产品决定新增 Excel 原生格式导出，同时保留 CSV 导出以兼容现有自动化流程。

### 变更目标

在现有用户数据导出功能基础上，新增 Excel（.xlsx）格式导出能力，解决 CSV 格式兼容性问题，满足运营团队对格式化报表的需求。

## 影响范围

### 文档影响

| 文档 | 章节 | 影响类型 | 风险等级 | 说明 |
|------|------|---------|---------|------|

| spec.md | ## 功能需求 | ADDED | 中 | 新增 FR-3 Excel 导出功能需求 |
| spec.md | ## 用户故事 | MODIFIED | 低 | 新增 Excel 导出相关用户故事 |
| spec.md | ## 验收标准 | MODIFIED | 低 | 新增 Excel 导出验收标准 |

### 代码影响

| 模块 | 影响类型 | 风险等级 | 说明 |
|------|---------|---------|------|
| 导出路由模块 | MODIFIED | 中 | 新增 Excel 导出接口和转换函数，复用现有查询逻辑 |
| 依赖管理 | ADDED | 低 | 引入 Excel 生成第三方库 |

### 设计稿影响

无设计稿影响——本项目无设计稿资源。

## 决策结论

- **决策**: 批准
- **理由**: 变更通过新增独立接口实现，不修改现有 CSV 导出逻辑，向后兼容无破坏性风险；运营团队有明确的格式化报表需求，业务价值明确。
