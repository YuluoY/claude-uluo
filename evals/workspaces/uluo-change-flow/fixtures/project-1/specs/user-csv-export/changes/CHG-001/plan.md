# 支持 Excel 导出 变更 Plan

> 日期: 2026-06-25 | 作者: huyongle | 关联变更 spec: ./spec.md

## 技术方案选择

### 方案对比

| 方案 | 优点 | 缺点 | 复杂度 |
|------|------|------|--------|
| 方案 A: exceljs | API 清晰，支持样式/公式/流式写入，社区活跃 | 包体积较大 | 中 |
| 方案 B: xlsx (SheetJS) | 功能全面，兼容性好 | 社区版不支持样式，Pro 版收费 | 中 |
| 方案 C: node-xlsx | 极简 API，上手快 | 不支持样式和流式写入，大数据量易 OOM | 低 |

### 选择结论

- **选择**: 方案 A: exceljs
- **理由**: 运营报表需要表头加粗和列宽自适应，exceljs 是唯一在社区版免费提供样式能力且支持流式写入的方案，能覆盖 10 万条数据的导出上限需求。
