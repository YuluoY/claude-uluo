# 用户认证

> 日期: 2026-06-15 | 作者: 李四 | 状态: 已批准

## 背景与动机

系统需要用户登录功能来保护敏感数据，目前使用 session 认证。

## 用户故事

| 编号 | 角色 | 故事 | 验收线索 |
|------|------|------|---------|
| US-1 | 用户 | 作为用户，我希望登录后能访问个人中心 | FR-1 |
| US-2 | 管理员 | 作为管理员，我希望能管理用户会话 | FR-2 |

### 非目标

- 不支持 OAuth 第三方登录
- 不支持双因素认证

## 功能需求

### FR-1: 登录
- **优先级**: P0
- **触发条件**: 用户提交登录表单
- **预期行为**: 创建 session，重定向到个人中心
- **边界条件**: 密码错误 5 次锁定账号

### FR-2: 会话管理
- **优先级**: P1
- **触发条件**: 管理员查看在线用户
- **预期行为**: 显示当前活跃 session 列表
- **边界条件**: 可强制下线指定用户

## 验收标准

- [ ] FR-1: 登录成功后重定向到 /dashboard
- [ ] FR-2: 管理员可查看和终止用户会话
