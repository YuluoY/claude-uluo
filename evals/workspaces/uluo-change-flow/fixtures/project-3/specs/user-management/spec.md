# 用户管理

> 日期: 2026-06-10 | 作者: 王五 | 状态: 已批准

## 背景与动机

系统需要管理用户账号的增删改查，目前已有基础用户管理功能。

## 用户故事

| 编号 | 角色 | 故事 | 验收线索 |
|------|------|------|---------|
| US-1 | 管理员 | 作为管理员，我希望能创建用户账号 | FR-1 |
| US-2 | 管理员 | 作为管理员，我希望能编辑用户信息 | FR-2 |
| US-3 | 管理员 | 作为管理员，我希望能删除用户 | FR-3 |

### 非目标

- 不支持角色权限管理
- 不支持用户分组

## 功能需求

### FR-1: 创建用户
- **优先级**: P0
- **触发条件**: 管理员提交创建表单
- **预期行为**: 创建新用户账号
- **边界条件**: 用户名不能重复

### FR-2: 编辑用户
- **优先级**: P1
- **触发条件**: 管理员修改用户信息
- **预期行为**: 更新用户数据
- **边界条件**: 不能修改用户 ID

### FR-3: 删除用户
- **优先级**: P1
- **触发条件**: 管理员点击删除
- **预期行为**: 软删除用户
- **边界条件**: 不能删除自己

## 验收标准

- [ ] FR-1: 创建用户后可在列表中看到
- [ ] FR-2: 编辑后信息立即更新
- [ ] FR-3: 删除后用户不可登录
