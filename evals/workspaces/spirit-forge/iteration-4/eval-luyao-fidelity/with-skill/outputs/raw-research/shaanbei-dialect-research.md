# 路遥小说中的陕北方言研究

## 核心方言词汇

### 称谓词
| 方言词 | 含义 | 使用场景 |
|--------|------|----------|
| 婆姨 | 妻子、已婚妇女 | "米脂的婆姨，绥德的汉" |
| 后生 | 年轻男子、小伙子 | 指代孙少安、孙少平等青年 |
| 女子 | 年轻姑娘 | 指农村女青年 |
| 干大 | 干爹 | 陕北农村称谓 |
| 二爸 | 二叔 | 家族称谓 |

### 生活境况词
| 方言词 | 含义 | 经典例句 |
|--------|------|----------|
| 烂包 | 糟糕、混乱、贫困至极 | "不再让家人过这样的烂包光景" |
| 惜惶 | 可怜 | 形容生活困苦 |
| 穷家薄业 | 家境贫寒 | 描述农民家庭 |
| 紧巴 | 拮据 | 经济困难 |
| 难肠 | 心里难过、纠结 | 形容人物内心苦楚 |
| 怯火 | 胆怯、害怕 | 表现人物心理 |

### 空间环境词

- 窑掌：窑洞深处
- 硷畔：窑洞前的平地

## A格BB重叠式（陕北方言特有形容词生动化构词）

"A格BB"是陕北方言中最具特色的构词方式，其中"格"为中缀衬字，起到增强语气、形象化的作用。

| 形式 | 构成 | 含义 |
|------|------|------|
| 绿格铮铮 | 绿 + 格 + 铮铮 | 绿得发亮、鲜嫩 |
| 蓝格莹莹 | 蓝 + 格 + 莹莹 | 蓝得透亮（常用于描写天空） |
| 笑格嘻嘻 | 笑 + 格 + 嘻嘻 | 笑盈盈的样子 |
| 软格溜溜 | 软 + 格 + 溜溜 | 非常柔软 |
| 红格丹丹 | 红 + 格 + 丹丹 | 红得艳丽 |
| 蓝格瓦瓦 | 蓝 + 格 + 瓦瓦 | 蓝得深沉 |
| 白格生生 | 白 + 格 + 生生 | 洁白干净 |
| 水格灵灵 | 水 + 格 + 灵灵 | 水灵灵的 |

出处：路遥《路遥文集》第3卷，人民文学出版社，2005年，第264-265页，引自信天游民歌。

## ABB式重叠（约124个，仅《平凡的世界》）
灰塌塌、黑森森、热烘烘、泪朦朦、汗淋淋、空朗朗、闹哄哄、静悄悄、绿油油、红艳艳

## 特色语气助词

- **哩**：替代普通话的"吧/吗/啊"。"姐姐，你不要急躁，事情总有我哩！"
- **呀**：感叹语气。"那两个娃娃哩！"
- 鼻音重、节奏慢、发音直硬，具有"鲁直、粗鄙、生动形象、幽默有趣而朴实本色"的特点

## 民间"炼话"（谚语）

- "金花配银花，西葫芦配南瓜"
- "忙婆姨生不下好娃"
- "跟上疯子扬黄尘"
- "果子是颗好果子，就是怕吃不到咱嘴里"
