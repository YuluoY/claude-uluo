# Paul Graham Style Reference

Quick reference card for PG writing style. Use alongside SKILL.md.

## THE GOLDEN RULE
**Write like you talk.** If you wouldn't say it to a friend, rewrite it.

## THE 10 GOTCHAS (NEVER BREAK)
1. No hedging
2. No phatic language
3. No fancy words
4. No boring passages
5. No complex sentences
6. No false modesty
7. No filler
8. No first-draft quality
9. No writing without learning
10. No detailed outlines

## PARAGRAPH RECIPE
Topic sentence → 1-2 supporting sentences → punch or transition
Length: 2-4 sentences. Each paragraph is a self-contained unit.

## STRUCTURAL ARC
1. Open with personal anecdote or bold claim
2. Rephrase the question
3. Accumulate examples (not logical proof)
4. Introduce framework/taxonomy
5. State contrarian implication
6. Close with aphoristic restatement

## SENTENCE CHECKLIST
- [ ] Sounds like conversation when read aloud?
- [ ] No hedging words?
- [ ] No phatic filler?
- [ ] Plain, Germanic words?
- [ ] Active voice?
- [ ] Contractions used?
- [ ] Direct address ("you")?

## ANALOGY RECIPE
Make every abstract point concrete with a vivid comparison.
Pattern: "X is like Y" or "X is the Y of Z"
Examples:
- "Informal language is the athletic clothing of ideas"
- "Startups are as unnatural as skiing"
- "Programming languages are half technology and half religion"

## FOOTNOTE RULE
Digressions → footnotes. Main text stays clean.

## TONE CALIBRATION
Too soft → add contrarian claim, cut hedging
Too harsh → add genuine curiosity, ethical optimism
Too academic → add contractions, direct address, anecdotes
Too casual → add framework, taxonomy, aphoristic compression

## VOCABULARY SWAPS
anomalous → weird
compelling → convincing
technique → trick
nevertheless → but
approximately → about
demonstrate → show
utilize → use
subsequently → then
consequently → so
additionally → also
regarding → about
individuals → people

## PG'S OWN BOTTOM LINE
"Just don't let a sentence through unless it's the way you'd say it to a friend."
