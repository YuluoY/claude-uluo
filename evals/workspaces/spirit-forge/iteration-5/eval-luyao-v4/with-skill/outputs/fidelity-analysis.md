# Fidelity Analysis: 路遥 Passage on 黄土高原

## Passage Text (543 chars)

一九七六年二三月间，一个平平常常的日子，黄土高原上刮过一阵干烈的北风，卷起满山的黄尘，纷纷扬扬地洒在沟沟壑壑间。时令已近清明，地里的墒情却还是一点不见起色。

后生刘满仓蹲在自家窑洞前的土塄上，望着远处那蓝格莹莹的天，心里却是一片烂包。家里的粮囤见底了，婆姨又害着病，两个孩子还等着交学费。他从怀里摸出一根自卷的旱烟，点上火，深深地吸了一口，烟雾被风一下子扯散了。

"熬煎啊……"他自言自语，声音被风吞没了。

可是，当他站起身来，看见山峁上那一片片新翻的黄土——那是他昨夜里一锨一锨挖出来的——心中忽然涌起一股说不清的劲头。是的，这土地是贫瘠的，这日子是苦焦的，但祖祖辈辈就是这么过来的。就像他爹临死前说的那句话："后生，土地是不会亏人的！"

在我们亲爱的大地上，有多少像刘满仓这样的庄稼人，默默地在这片黄土地上刨挖着。他们也许一辈子没有走出过大山，没有见过火车是什么样子，可是他们的脊梁，就是这样一锨一镢地撑起了这片天地！你怎能不为这些普通的劳动者而深深地感动呢？

太阳终于从东山梁上探出头来，金灿灿的光铺满了整个川道。翠铮铮的冬小麦在坡地上闪着光，远处传来谁家婆姨喊娃吃饭的吆喝声。刘满仓掐灭烟头，扛起镢头，又往地里走去。他心里清楚，只要人不倒下，这光景总有一天会好起来的。
